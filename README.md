# Контраст

Интерактивное визуальное эссе на русском: заметить отличие → увидеть влияние контекста → направить внимание → услышать разницу → пережить неожиданность → потерять различия.

[Открыть опубликованный лонгрид](https://contrast-notice-the-difference.bubblyoasis128.chatgpt.site/) · [Сценарий и последовательность сцен](STORYBOARD.md)

## Локальный запуск

```sh
npm run dev
```

Откройте http://localhost:4173. Сборка и установка зависимостей не нужны. Статические файлы находятся в `dist/`, шрифты хранятся локально.

```sh
npm run check
npm test
```

Звуковой опыт проходит последовательно: первая пара (до + ми) → личное впечатление → вторая пара (до + ре-бемоль) → личное впечатление → объяснение. Ответы не оцениваются и не отправляются на сервер. Звук включается пользователем и останавливается через четыре секунды. Прерванное прослушивание не продвигает опыт. Объяснение доступно без звука; после него обе пары можно послушать повторно.

Два пика на эквалайзере показывают основные частоты на условной шкале 200–400 Гц. Их ширина не является измерением спектра или моделью диссонанса. Воспроизводятся мягкие синтетические тоны с обертонами.

Прокрутка управляет состояниями точек и раскрытием мягкой формы. Круги занимают полный экран. Иерархия плаката изначально выключена. Финал проходит через серый и белый, возвращает к заголовку и сбрасывает опыты. При системном уменьшении движения показаны статичные сцены и кнопка возврата вместо автоматической петли.

Научные источники и границы авторской интерпретации указаны перед финалом.
