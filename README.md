# Контраст

Интерактивное визуальное эссе на русском языке.

**Тезис.** Мы понимаем мир, отделяя одно от другого: чем яснее различие, тем легче ориентироваться.

**О публикации.** Три короткие истории проверяют эту мысль с разных сторон. Простые фигуры, которые легко различить, сразу становятся персонажами. Две соседние ноты слух разделяет с трудом, а октава почти сливается в один звук. Рисованный тритон выделяется среди векторных фигур не цветом, а происхождением, пока не приходит его море и чужими не становятся фигуры. Финал убирает все различия.

## Маршрут

1. **Вход** `#top` — «КОНТРАСТ», тезис и кнопка «читать».
2. **Поле точек** — пролёт над полем одинаковых точек; одна краснеет и убегает.
3. **Мультфильм** `#principle` — круг, большой и маленький квадраты: нападение и спасение. Сцена играет сама (около 22 с), `Esc` сразу показывает финал.
4. **Перелом в темноту** — прокрутка растит большой квадрат, пока он не зальёт экран.
5. **Бал** `#sound` — мелодия, подсветка клавиш и график частот; финал на полутон срывает танец.
6. **Объяснение и октава** — основные тона и обертоны; повтор с октавой, фигуры сливаются.
7. **Тритон и море** `#stranger` — тритон проламывает пианино (звучит тритон, до + фа-диез), затем лежит на волнах; «Контекст влияет на контраст». Источники и кредиты.
8. **Финал** `#disappearance` — «Без разницы»; кнопка «Вернуть различия» возвращает к началу.

## Почему браузер

Мысль эссе держится на свойствах среды: на времени (сцены играют сами и выдерживают паузы), прокрутке (квадрат растёт, читатель спускается к морю), звуке (Web Audio играет мелодию и измеряет её спектр), интерактивности (клавиатура играет мышью, касанием и клавишами A–K) и изменении состояния (финал стирает оформление, кнопка его возвращает). На бумаге или в видео пропали бы звук, собственная игра читателя и связь «слышу → вижу».

**Основной приём** — звук, который видно: мелодия, подсветка клавиш и измеренный график частот показывают одно и то же различие сразу слуху и глазу. Поддерживают его самоиграющий мультфильм, рост квадрата при прокрутке и море.

## Доступность

- Сцены описаны для экранных чтецов; у мультфильма есть четыре статичных кадра с подписями (низкое окно, уменьшение движения, нет JavaScript).
- При уменьшении движения остаются звук, подсветка и статичный кадр спектра; тритон показан неподвижным.
- Контраст текста: тушь на бумаге 15,3 : 1, приглушённый текст 5,6 : 1, тушь на акценте 4,7 : 1.
- Пианино играет с клавиатуры, мультфильм пропускается по `Esc`; без горизонтальной прокрутки при 390 px и при увеличении 200 %.

## Локальный запуск

```sh
npm run dev     # http://localhost:4173
npm run check
npm test
```

Сборки нет: `dist/` содержит редактируемые исходники статического сайта, шрифты лежат локально. Версия ассетов в query (`?v=credits-2`) должна совпадать во всей цепочке импортов.

## Публикация

GitHub Pages публикует `dist/` после обновления `main`. Workflow **Deploy GitHub Pages** сначала проверяет JavaScript и запускает тесты.
