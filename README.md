# Контраст

Интерактивное визуальное эссе на русском: заметить отличие → направить внимание → услышать разницу → пережить неожиданность → потерять различия.

[Открыть опубликованный лонгрид](https://pentaoo.github.io/contrast/) · [Сценарий и последовательность сцен](STORYBOARD.md) · UI-kit: `dist/ui-kit.html`

## Публикация

GitHub Pages автоматически публикует содержимое `dist/` после каждого обновления `main`. Workflow сначала проверяет JavaScript и запускает тесты. Его также можно запустить вручную из вкладки Actions: **Deploy GitHub Pages**.

Настройки Pages используют источник **GitHub Actions**. Установка зависимостей и сборка не требуются; в публикацию попадают только статические файлы сайта.

## Локальный запуск

```sh
npm run dev
```

Откройте http://localhost:4173. Сборка и установка зависимостей не нужны. Статические файлы находятся в `dist/`, шрифты хранятся локально.

```sh
npm run check
npm test
```

Звуковая микроистория: короткая весёлая мелодия со сбоем в финале → объяснение → то же исполнение с тоникой → конфетти по бокам и продолжение чтения. Обе версии длятся около девяти секунд. В первом финале звучат только C4 + D-flat4 (малая секунда), во втором — C4 + C5 (тоника, удвоенная в октаву). Пара удерживается около 2,6 секунды; предыдущие голоса полностью заканчиваются до её начала. Звук синтезируется локально с быстрым ударным началом и затухающими обертонами.

Эквалайзер над пианино показывает измеренный FFT-спектр в диапазоне 200–4000 Гц. Для последних двух нот используются отдельные анализаторы и два цвета, связанные с подсветкой клавиш. Измеренный финальный кадр остаётся для сравнения после затухания. У абзаца об основном тоне и обертонах на графике появляются подписи; дальнейшая прокрутка увеличивает основные тона и скрывает обертоны. Приближение завершается, пока этот абзац ещё виден. Текст предупреждает о фокусе только на основных тонах. В увеличенном виде используется одинаковый для обеих пар диапазон 240–560 Гц. Прокрутка назад возвращает полный спектр; аудио и исходные FFT-данные не меняются. Искусственный шум и уширение пиков не добавляются; ширина пиков не используется как модель шероховатости. Объяснение отличает биения близких составляющих от точного совпадения некоторых гармоник октавы.

После полного первого исполнения измеренный спектр и две клавиши сохраняются. Раскрытие объяснения сохраняет позицию страницы: браузер не перескакивает к финальной кнопке. Крупные абзацы объяснения расположены в обычном потоке страницы и физически пролистываются вверх; пианино и спектр закреплены внизу окна. Все абзацы доступны скринридеру в исходном порядке. Кнопка исправленной мелодии появляется у последнего абзаца. Объяснение можно открыть и без звука. Исправленная мелодия — финальное действие после объяснения. Конфетти запускается только после полного окончания исправленной версии, один раз за цикл. Прерывание, скрытие вкладки и возврат к началу отменяют ожидающие звуки и эффекты. При уменьшении движения остаются звук, подсветка и один статичный измеренный кадр финала; толчок инструмента, бегущий эквалайзер и конфетти отключаются. В музыкальной сцене используются один крупный стиль для заголовка и объяснения, один обычный стиль для подписей и одна основная кнопка.

На пианино можно играть самому: мышью (с протяжкой по клавишам), касанием (несколько пальцев — аккорд) и клавишами компьютера по физическому расположению, поэтому работает и в русской раскладке: `A`–`K` — белые клавиши от C4 до C5, `W E T Y U O P` — чёрные, `L` и `;` продолжают вверх. Спектр показывает реально звучащий сигнал, подпись называет ноты, а для двух нот — интервал (`notes.js`). Свободная игра не продвигает историю и недоступна, пока звучит мелодия; после затухания возвращается сохранённый кадр финала. При уменьшении движения спектр во время свободной игры не анимируется.

## UI-kit

Все стили собраны в `dist/styles.css` по разделам: токены → основа → типографика → раскладка → компоненты → сцены → адаптивность. Витрина — `dist/ui-kit.html` (не связана с лонгридом ссылками, `noindex`).

- Цвет: `--paper`, `--paper-deep`, `--ink`, `--muted`, `--line`, единственный акцент `--accent`, `--sage` для второй ноты. Текст на акцентной кнопке — тушью.
- Текст: пять ролей — `h2` (`--text-h1`), `.h2`, `.voice` (курсив Georgia для мостов и финальных фраз), `.body-copy`, `.label` (14 px). Oswald — только обложка.
- Сетка: `.container` задаёт общие поля `--gutter` и ширину `--measure` 1240 px; отступы — `--space-1…7`.
- Обложка: оранжевая точка после «КОНТРАСТ» — кнопка «читать» (`.read-button`, макет Figma node 422:921), ведёт к первой сцене. Её размеры заданы в долях кегля заголовка, нижний край стоит на базовой линии; подпись не мельче 14 px.
- Компоненты: `.button--primary`, `.button--outline`, `.link-button`, `.circle-link`, `.sources`, пианино; `.on-ink` переключает их для тёмной сцены.

Первая сцена — история оранжевой точки (`dist/geometry-story.js`). Одна точка из поля становится оранжевым кругом; большой тёмный квадрат его преследует, маленький оранжевый помогает уйти; затем вопрос «В какой момент эти фигуры стали персонажами?». Когда сцена занимает окно, она проигрывается сама (около 18 с), а прокрутка на это время заблокирована; по окончании, по `Esc` или через страховочный таймер прокрутка возвращается. Кадр в одном SVG считает чистая функция `storyFrame(progress, view)` по доле прошедшего времени. Координаты — в единицах «диаметр круга», SVG не растягивается по осям. Тесты (`tests/geometry-story.test.js`) проверяют границы прогресса, повторяемость кадра и отсутствие взаимного проникновения фигур. При уменьшении движения, в окне ниже 600 px и без JavaScript показаны четыре статичных кадра с подписями. Ориентир — опыт Хайдера и Зиммель (1944), сцена — авторская адаптация.

Прокрутка также управляет раскрытием мягкой формы. После истории с фигурами идёт плакат с изначально выключенной иерархией. Финал проходит через серый и белый, возвращает к заголовку и сбрасывает опыты. При системном уменьшении движения показаны статичные сцены и кнопка возврата вместо автоматической петли.

Научные источники и границы авторской интерпретации указаны перед финалом.
