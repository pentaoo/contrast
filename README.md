# Контраст

Интерактивное визуальное эссе на русском. Общий вопрос: когда различие помогает понять, а когда заставляет задержаться?

[Опубликованный лонгрид](https://pentaoo.github.io/contrast/) · [Текущий сценарий](STORYBOARD.md)

## Локальный запуск

```sh
npm run dev
```

Откройте http://localhost:4173. Сборка и установка зависимостей не нужны: `dist/` содержит редактируемые исходники статического сайта. Шрифты хранятся локально.

```sh
npm run check
npm test
```

## Порядок чтения

Пролог «Родилась она» (`dist/origin.js`) сохраняет рассказ о младенце и психоанализе: «хорошо/плохо», мама, оттенки ощущений и дифференциация. Теория обозначена как модель описания, переход к точке дополнен фразой «А мы попробуем разглядеть её среди других». Пять надписей и исходная длина 800svh сохранены. Квадрат распадается на формы, узор становится полем точек. При уменьшении движения, в низком окне и без JavaScript текст стоит в обычном потоке.

История точки (`dist/geometry-story.js`) управляется прокруткой: пролёт над полем, побег из сетки, преследование и спасение. Секция занимает 1250svh. После ухода героев есть примерно одна высота окна для чтения вопроса и ответа о движениях и ролях. Затем квадрат вырастает в фон музыкальной сцены. Прокрутка свободна и обратима. В низком окне, при уменьшении движения и без JavaScript показаны статичные кадры. Это авторская адаптация опыта Хайдера и Зиммель (1944).

Обложка → пролог → побег точки и история фигур → бал, музыкальное объяснение и другой финал → тритон, море и темнота → падающие ссылки на источники → итоговый текст на чёрном фоне → веб-ринг.

Первое исполнение заканчивается C4 + D-flat4 (полутон). Затем идут короткие абзацы об основных тонах, обертонах и биениях. Текст различает слияние нот, шероховатость, приятность и завершённость. Следующая дорожка прокрутки запускает ту же фразу с C4 + C5 (октавой) в финале. Ритм, тембр, динамика и предыдущие ноты совпадают. Каждая мелодия длится около девяти секунд.

После полного затухания октавы, без дополнительного нажатия, сверху падает рисованный тритон. В момент контакта звучат C4 + F-sharp4, клавиатура рассыпается. Тритон продолжает падение, обломки уходят вниз и исчезают. Отдельной кнопки падения и остановки на сломанном пианино нет. Скролл остаётся свободным; после сцены доступен переход к следующей истории. Звук удара и визуальное действие используют один таймер Web Audio. Кадры предварительно загружаются во время чтения объяснения.

Возврат выше музыкальной дорожки и уход из музыкальной секции останавливают исполнение. Звук разблокируется первым нажатием, касанием или клавишей на странице, например кнопкой «читать». Если этого не было, появляется «Включить звук», а визуальная сцена продолжается. Отдельной кнопки повторного исполнения нет.

Клавиатура показывает три октавы от C3 до C6. Чёрные клавиши объединены в группы по две и три; крайние клавиши в каждой группе смещены относительно стыков белых. Подсветка соответствует MIDI-нотам исполнения. Между прослушиваниями можно играть мышью, касанием или физическими клавишами A–K; надпись у спектра называет ноты и интервал. Во время мелодии, поломки и после исчезновения клавиатуры свободная игра отключена. Сохранены UI-kit и полноэкранная сетка точек из GitHub-версии.

Спектр измеряется через Web Audio FFT в диапазоне 200–4000 Гц. Для двух финальных нот используются отдельные анализаторы и цвета, совпадающие с подсветкой клавиш. Измеренный кадр сохраняется после затухания. У абзаца об основных тонах появляются подписи, затем диапазон сужается до 240–560 Гц. Прокрутка назад возвращает полный спектр. Звук и измеренные данные при этом не меняются. Ширина пиков не служит моделью диссонанса; шум и искусственное уширение не добавляются.

Крупные абзацы музыкального объяснения расположены в обычном потоке страницы; пианино и спектр закреплены внизу. Раскрытие объяснения сохраняет позицию чтения. При уменьшении движения остаются звук, подсветка и один статичный измеренный кадр финала. Вместо падения показана одна неподвижная поза тритона, затем инструмент скрывается без разлёта и перемещения.

[Постановка сцены](TRITON.md) · [Промпты исходных кадров](TRITON-PROMPTS.md) · [Витрина UI-kit](dist/ui-kit.html).

После моря начинается отдельная глава исследований (`dist/sources.js`). Читатель листает вглубь и встречает семь ссылок, ещё не достигших дна: они проходят снизу вверх по разным диагоналям, вращаются и удаляются. На экране — только подчёркнутые авторы, год и стрелка; полное название работы доступно при наведении. Длина — 960svh. Прокрутка обратима; переход клавишей Tab останавливает выбранную ссылку горизонтально в центре для чтения. При уменьшении движения, в низком окне и без JavaScript остаётся обычный список.

Итоговый текст `#conclusion` находится внутри чёрной главы источников и прямо объясняет связь контраста и контекста. Отдельного экрана и повторной иллюстрации героев нет. Вывод набран одним крупным абзацем. Кнопка «Прочитать заново» занимает всю ширину блока, возвращает к заголовку и сбрасывает опыты. Источники находятся перед выводом; после него — веб-ринг. Танец героев — авторская постановка, сайт не измеряет музыкальное восприятие читателя.

## Публикация

GitHub Pages публикует `dist/` после обновления `main`. Workflow **Deploy GitHub Pages** сначала проверяет JavaScript и запускает тесты. Источник Pages — **GitHub Actions**. Локальные изменения сами по себе не обновляют опубликованный сайт.
