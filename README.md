## Публикация

GitHub Pages автоматически публикует содержимое `dist/` после каждого обновления `main`. Workflow сначала проверяет JavaScript и запускает тесты. Его также можно запустить вручную из вкладки Actions: **Deploy GitHub Pages**.

Настройки Pages используют источник **GitHub Actions**. Установка зависимостей и сборка не требуются; в публикацию попадают только статические файлы сайта.

## Локальный запуск

```sh
npm run dev
```

Откройте http://localhost:4173. Сборка и установка зависимостей не нужны. Статические файлы находятся в `dist/`, шрифты хранятся локально.

```sh
npm run check
npm test
```

Звуковая микроистория: короткая весёлая мелодия со сбоем в финале → объяснение → то же исполнение с тоникой → конфетти по бокам и продолжение чтения. Обе версии длятся около девяти секунд. В первом финале звучат только C4 + D-flat4 (малая секунда), во втором — C4 + C5 (тоника, удвоенная в октаву). Пара удерживается около 2,6 секунды; предыдущие голоса полностью заканчиваются до её начала. Звук синтезируется локально с быстрым ударным началом и затухающими обертонами.

Эквалайзер над пианино показывает измеренный FFT-спектр в диапазоне 200–4000 Гц. Для последних двух нот используются отдельные анализаторы и два цвета, связанные с подсветкой клавиш. Измеренный финальный кадр остаётся для сравнения после затухания. У абзаца об основном тоне и обертонах на графике появляются подписи; дальнейшая прокрутка увеличивает основные тона и скрывает обертоны. Текст предупреждает о фокусе только на основных тонах. В увеличенном виде используется одинаковый для обеих пар диапазон 240–560 Гц. Прокрутка назад возвращает полный спектр; аудио и исходные FFT-данные не меняются. Искусственный шум и уширение пиков не добавляются; ширина пиков не используется как модель шероховатости. Объяснение отличает биения близких составляющих от точного совпадения некоторых гармоник октавы.

После полного первого исполнения измеренный спектр и две клавиши сохраняются. Крупные абзацы объяснения расположены в обычном потоке страницы и физически пролистываются вверх; пианино и спектр закреплены внизу окна. Все абзацы доступны скринридеру в исходном порядке. Кнопка исправленной мелодии появляется у последнего абзаца. Объяснение можно открыть и без звука. Исправленная мелодия — финальное действие после объяснения. Конфетти запускается только после полного окончания исправленной версии, один раз за цикл. Прерывание, скрытие вкладки и возврат к началу отменяют ожидающие звуки и эффекты. При уменьшении движения остаются звук, подсветка и один статичный измеренный кадр финала; толчок инструмента, бегущий эквалайзер и конфетти отключаются. В музыкальной сцене используются один крупный стиль для заголовка и объяснения, один обычный стиль для подписей и одна основная кнопка.

Прокрутка управляет состояниями точек и раскрытием мягкой формы. После поля точек сразу идёт плакат с изначально выключенной иерархией. Финал проходит через серый и белый, возвращает к заголовку и сбрасывает опыты. При системном уменьшении движения показаны статичные сцены и кнопка возврата вместо автоматической петли.

Научные источники и границы авторской интерпретации указаны перед финалом.
