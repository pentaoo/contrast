# Контраст

Интерактивное визуальное эссе на русском. Общий вопрос: когда различие помогает понять, а когда заставляет задержаться?

[Опубликованный лонгрид](https://pentaoo.github.io/contrast/) · [Текущий сценарий](STORYBOARD.md)

## Локальный запуск

```sh
npm run dev
```

Откройте http://localhost:4173. Сборка и установка зависимостей не нужны: `dist/` содержит редактируемые исходники статического сайта. Шрифты хранятся локально.

```sh
npm run check
npm test
```

## Порядок чтения

Короткое вступление → два исполнения одной мелодии → поле точек → одно объявление в двух состояниях иерархии → история с нарушением ожидания → обратимый белый финал.

В музыкальном опыте меняется только одна нота последнего созвучия. Первый вариант заканчивается C4 + D-flat4 (полутон), второй — C4 + C5 (октава). Ритм, тембр, динамика и остальная фраза совпадают. Каждое исполнение длится около девяти секунд. Объяснение появляется после полного второго исполнения или по кнопке «Без звука». Первый вариант можно повторить перед вторым; в конце объяснения доступны оба. Прерывание и скрытие вкладки останавливают звук без продвижения сценария. Конфетти и толчка инструмента нет: ни один вариант не отмечается как правильный.

Клавиатура показывает три октавы от C3 до C6. Чёрные клавиши объединены в группы по две и три; крайние клавиши в каждой группе смещены относительно стыков белых. Подсветка соответствует MIDI-нотам исполнения.

Спектр измеряется через Web Audio FFT в диапазоне 200–4000 Гц. Для двух финальных нот используются отдельные анализаторы и цвета, совпадающие с подсветкой клавиш. Измеренный кадр сохраняется после затухания. У абзаца об основных тонах появляются подписи, затем диапазон сужается до 240–560 Гц. Прокрутка назад возвращает полный спектр. Звук и измеренные данные при этом не меняются. Ширина пиков не служит моделью диссонанса; шум и искусственное уширение не добавляются.

Крупные абзацы музыкального объяснения расположены в обычном потоке страницы; пианино и спектр закреплены внизу. Раскрытие объяснения сохраняет позицию чтения. При уменьшении движения остаются звук, подсветка и один статичный измеренный кадр финала.

Финал проходит через серый и белый и ждёт действия читателя. На белом фоне видна кнопка «Вернуть различия». Она возвращает к заголовку, восстанавливает оформление и сбрасывает оба опыта. Можно также прокрутить страницу назад. Автоматического перезапуска нет. При уменьшении движения доступна статичная сцена с той же кнопкой.

Источники и границы авторской интерпретации раскрываются перед финалом. «Зависший переход» — образ впечатления, а не объяснение работы слуха. На сайте не измеряется музыкальное восприятие читателя.

## Публикация

GitHub Pages публикует `dist/` после обновления `main`. Workflow **Deploy GitHub Pages** сначала проверяет JavaScript и запускает тесты. Источник Pages — **GitHub Actions**. Локальные изменения сами по себе не обновляют опубликованный сайт.
