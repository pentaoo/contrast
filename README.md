# Контраст

Интерактивное визуальное эссе на русском: восприятие, музыка, визуальная иерархия и контраст ожиданий.

## Локальный запуск

```sh
npm run dev
```

Откройте http://localhost:4173. Сборка и установка зависимостей не нужны: готовый сайт находится в `dist/`, шрифты хранятся локально.

```sh
npm run check
```

Схематичный спектральный эквалайзер показывает два основных тона на приближённой шкале 200–400 Гц, выделяя наложение полос. Пример с кругами занимает всю ширину и высоту экрана. Звук включается пользователем и останавливается через четыре секунды. Финал при прокрутке стирает контраст, проходит через серый и белый и возвращает в начало. С системной настройкой уменьшения движения анимации и автоматический перезапуск отключены; доступна кнопка возврата.

Научные источники и границы авторской интерпретации указаны в раскрывающемся блоке перед финалом.
